# Sugestão de histórico de commits

O estudo exige pelo menos 6 commits. Uma sequência possível:

1. `Tarefa 1: Configuração inicial e primeiro teste com Docker`
2. `Tarefa 1: Adiciona documentação dos comandos Docker`
3. `Tarefa 2: Cria aplicação web com Dockerfile`
4. `Tarefa 3: Configura banco MySQL e scripts`
5. `Tarefa 4: Adiciona aplicação Flask e Docker Compose`
6. `Tarefa 4: Adiciona documentação e evidências finais`

Faça os commits durante a execução real das tarefas, adicionando os screenshots correspondentes.
